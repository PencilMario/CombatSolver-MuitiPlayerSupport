# 多人模式搜索回合数实现计划

## 目标

多人战斗自动使用设置的本地玩家搜索回合上限，默认 4 回合；单人行为不变。队友不执行预测动作，也不消耗模拟 RNG。

## 方案与边界

- `SolverSettingsData` / `SolverSettingsSnapshot` 增加 `MultiplayerSearchTurnLimit`，默认 4，校验范围 1–12。
- 设置页增加整数输入，仅多人搜索策略读取；1 表示当前回合。
- `SearchPolicySnapshot` 携带多人标识和有效回合层上限。Search 在回合层边界停止并报告 `TurnLimit`。
- 多人结果不生成 continuation，只部署当前本地玩家回合；单人继续现有 continuation 和时间/节点策略。
- 保持现有 `AdvanceRound` 的本地玩家 + 敌方推进，不插入队友行动或随机调用。

## 原子任务

1. 先添加设置序列化/默认值/范围及策略捕获回归断言，确认新字段缺失时失败。
2. 增加设置 UI 输入、重载和保存回调。
3. 扩展搜索策略快照与回合层循环，替换多人硬编码单回合判断。
4. 更新日志、测试矩阵和初始化诊断字段。
5. 执行最小测试、Release 构建、边界门禁并提交。

## 验证

- 设置测试：默认 4、JSON 往返、1 与 12 可接受、0 与 13 拒绝。
- 单人 `SMOKE-002` 回归。
- 真实多人四回合搜索需在游戏内验证；当前无人测试没有多人建局/回放导入器，不以单人场景替代。
