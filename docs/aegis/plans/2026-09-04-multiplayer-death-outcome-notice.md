# 多人死亡路线提示实现计划

## 目标

多人搜索仅在模拟器已明确结算本地玩家死亡时显示“未找到生还路线”。回合、节点、时间边界或威胁投影不能单独触发该提示。

## 范围

- Search 结果携带请求是否属于多人限制搜索的只读事实。
- UI snapshot 是唯一的提示可见性判定点：单人沿用 `OnlyDeathRoutesFound`；多人额外要求 `Snapshot.PlayerDead`。
- 使用纯判定 helper 覆盖多人投影死亡、多人实际死亡和单人既有显示三种情况。

## 验证

- 先让新断言在没有 helper 时失败。
- Release 构建、结构边界门禁。
- 如游戏进程未占用，再运行现有控制器生命周期无人测试；该测试不替代真实多人场景。
